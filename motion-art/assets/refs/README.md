# Reference images

The skill reads full-size reference paintings from this folder (file names in
`references/visual-signature.md`). They come from the third-party "Argon Paintings" gallery,
which declares no licence, so they are not in this repository.

To use them, save the gallery images you want to study here under those file names. Without
them, work from the rules and descriptions in `references/visual-signature.md`.
